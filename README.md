# 책장 · 웹캠 도서 기록

웹캠으로 책의 ISBN 바코드를 읽고, 국립중앙도서관 소장자료 API에서 서지정보를 조회해 내 컴퓨터의 Excel 파일에 저장하는 Windows용 로컬 웹앱입니다.

## 주요 기능

- **바코드 인식**: 연결된 웹캠 선택, 좌우 반전 미리보기, 작은 바코드 확대 모드, 현재 화면 정밀 인식
- **사진 인식**: JPG·PNG·WebP 바코드 사진에서 ISBN 읽기
- **서지정보 조회**: ISBN-10·ISBN-13 검증과 변환, 국립중앙도서관 조회, 여러 후보 중 선택
- **도서 관리**: 신규 등록, 정보 수정, 등록 취소, 중복 ISBN의 권수 추가, ISBN 없는 도서 수동 등록
- **목록 검색과 페이지 이동**: 기본 20개씩 표시, 20·30·40·50개 보기, 검색 결과에 맞춘 페이지 수 변경, 브라우저에 보기 개수 저장
- **Excel 저장**: 저장 경로 설정, 파일 다운로드, Windows 파일 탐색기로 저장 폴더 열기
- **백업과 복원**: 변경 전 자동 백업, 보관 개수 설정, 전체 서가 복원
- **저장 보호**: 파일 잠금·외부 변경 감지와 동일 요청의 중복 저장 방지

## 실행 환경

- Windows 10/11
- Python 3.12 이상
- Chrome 또는 Edge 등의 최신 브라우저
- 웹캠: 선택 사항. ISBN 직접 입력이나 수동 등록으로도 사용할 수 있습니다.
- 국립중앙도서관 API 키 및 인터넷: 서지정보 조회에 필요합니다.

## 설치와 실행

1. 이 저장소를 내려받아 압축을 풀거나 `git clone`으로 복제합니다.
2. `app\setup.cmd`를 실행합니다. 가상환경 생성과 패키지 설치에는 인터넷이 필요합니다.
3. 루트의 **책장_실행.cmd** 또는 `app\start.cmd`를 실행합니다.
4. 자동으로 열린 브라우저를 사용합니다. 직접 접속할 주소는 **http://127.0.0.1:8765** 입니다.

PowerShell에서 직접 설치하려면 다음과 같이 실행합니다.

```powershell
cd app
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

다른 포트를 사용하거나 브라우저 자동 실행을 끄려면 다음 옵션을 사용합니다.

```powershell
.\.venv\Scripts\python.exe run.py --port 8766 --no-browser
```

실행 창은 사용 중에 열어 둡니다. 종료는 화면 상단의 **종료** 또는 실행 창의 `Ctrl+C`로 합니다. 브라우저 탭을 닫는 것만으로는 서버가 종료되지 않습니다.

## API 키 설정

국립중앙도서관 소장자료 API 사용 키를 발급받은 뒤 앱의 **설정**에 입력하고 저장합니다. **연결 확인**으로 조회 가능 여부를 확인할 수 있습니다.

Windows에서 입력한 키는 현재 사용자 계정으로 암호화해 저장됩니다. 다른 컴퓨터나 Windows 계정에서는 새로 입력해야 합니다. 환경변수 `NL_API_KEY`로도 지정할 수 있으며, 환경변수가 저장된 키보다 우선합니다.

**저장소에는 API 키나 개인 설정을 포함하지 않습니다.** 실행 시 자신의 키를 설정하세요.

## 책 등록하기

1. 카메라를 켜고 책 뒷면의 ISBN 바코드 전체와 좌우 여백을 비춥니다. 또는 ISBN을 직접 입력하거나 사진을 선택합니다.
2. 조회된 제목·저자·출판사 등을 확인하고 권수·소장 위치·메모를 입력합니다.
3. **서가에 저장**을 누릅니다.
4. **다음 책**을 눌러 다음 바코드를 읽습니다.

같은 ISBN이 이미 있으면 확인 후 권수를 추가할 수 있습니다. 목록의 **수정**으로 기록을 고치고, **취소**로 해당 도서의 등록 전체를 제거합니다. 조회되지 않는 도서는 직접 입력해 등록할 수 있습니다.

목록 오른쪽의 **20개씩 보기**에서 20·30·40·50개 중 선택합니다. 목록 아래의 처음·이전·페이지 번호·다음·마지막 버튼으로 이동합니다. 검색이나 보기 개수 변경 시 첫 페이지로 돌아갑니다.

## 저장 위치와 백업

설정이 없는 새 설치의 기본 저장 위치는 다음과 같습니다.

```text
app/data/소장도서.xlsx          # 도서 목록: 첫 저장 시 생성
app/data/settings.json        # 저장 경로·백업 개수·암호화된 API 키
app/data/backups/소장도서/     # 변경 전 자동 백업
```

**설정**에서 `.xlsx` 파일명을 포함한 절대 경로를 지정할 수 있습니다. 저장 경로를 바꾸면 해당 파일을 읽고 쓰며, 기존 목록을 자동으로 이동하지는 않습니다. 사용자 PC에 이미 설치된 앱은 설정에 지정된 다른 폴더를 사용할 수 있습니다. 화면 하단의 **저장 파일** 경로를 확인하세요.

- 앱에서 저장할 때는 Excel 파일을 닫아 주세요.
- Excel에서 기록을 수정한 뒤에는 목록의 **새로고침**으로 다시 읽습니다.
- 숨겨진 `_meta`, `_operations` 시트, 열 이름과 등록 ID는 유지해야 합니다. 앱 전용 형식의 파일을 사용하세요.
- 백업은 Excel 파일 옆의 `backups/파일이름/`에 생성하며 기본 20개를 보관합니다.
- **설정 → 백업에서 복원**은 서가 전체를 해당 시점으로 되돌립니다. 복원 직전 파일도 백업합니다.
- **저장 폴더** 버튼으로 파일 탐색기를 열거나 Excel 파일을 다운로드할 수 있습니다.

## 개인정보와 동작 범위

서버는 `127.0.0.1`에서 실행됩니다. 카메라 영상과 사진은 브라우저 안에서 처리하며 서버에 업로드하거나 저장하지 않습니다. 서지정보를 조회할 때는 국립중앙도서관에 API 키와 ISBN 등의 검색 조건을 전송합니다. 도서 목록·위치·메모는 로컬 Excel에 보관합니다.

바코드 해독에는 로컬로 포함된 ZXing JS·WASM 모듈을 사용합니다. 런타임에 CDN에서 인식 모듈을 내려받지 않습니다. 패키지 설치가 끝난 뒤에는 인터넷 없이 카메라 인식·수동 입력·로컬 저장을 사용할 수 있습니다.

## 카메라 사용 시 참고

가는 바코드 선의 선명도, 초점 거리, 조명과 반사에 따라 인식률이 달라집니다. 작은 바코드 확대는 원본에 없는 세부를 복원하지 못합니다. 자동 인식이 어려우면 정밀 인식·선명한 사진·ISBN 직접 입력을 사용하세요.

카메라가 잡히지 않으면 브라우저와 Windows의 카메라 권한, USB 연결, 다른 프로그램의 카메라 사용 여부를 확인하세요. 일부 카메라에서는 설정 FPS와 실제 영상 FPS가 다를 수 있으며, 모든 장치의 인식률과 프레임 속도를 보장하지 않습니다.

저장 폴더가 열리지 않으면 앱을 종료한 뒤 **책장_실행.cmd를 직접 실행**해 보세요. 실행 환경의 권한 제한에 따라 탐색기 실행이 차단될 수 있습니다.

## 소스 구조

```text
README.md
책장_실행.cmd
app/
  app.py                  # 로컬 HTTP API와 접근 보호
  run.py                  # 서버 시작·종료와 중복 실행 방지
  settings.py             # 설정과 Windows API 키 암호화
  domain.py               # ISBN 검증과 서지정보 변환
  storage.py              # Excel 저장·백업·복원
  desktop.py              # Windows 저장 폴더 열기
  setup.cmd / start.cmd   # 설치·실행
  requirements.txt        # Python 의존성
  static/                 # 화면·바코드 해독 모듈·라이선스
  tests/                  # 서버 기능 검사
```

## 개발 검사

```powershell
cd app
.\.venv\Scripts\python.exe -m pytest tests -q
```

검사에는 별도 임시 파일을 사용합니다. 실제 서가 파일을 검사 데이터로 사용하지 마세요.
